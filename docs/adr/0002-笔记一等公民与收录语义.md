# ADR 0002 — 笔记是全局一等公民，做笔记即收录

- 状态：Accepted（2026-09-26 定，2026-10-03 随机考助手删除而暂失实现对象，
  2026-10-06 由 `docs/adr/0005` 接为错题助手的正式方向并落地其口径）
- 日期：2026-09-26

> 本票的三条理念（笔记按题目 ID 全局唯一、做笔记即收录、缺快照就降级并提示补全）
> 现在都归错题助手实现，具体作用域、存储形状、多标签合并语义与界面位置在 ADR 0005，不在这里。
> 原票写死的界面范围（五种来源、解析页内联笔记）属于已删除的机考助手，2026-10-06 按现状改写。

## 背景

旧版笔记依附错题本：只有错题页/收藏页有笔记入口，做对的题无处记笔记。新版理念（用户 2026-09-26 确定）：
不管错没错，随时可以在题目旁记笔记；记了就要找得到。

## 决策

1. 笔记按**题目 ID** 全局唯一。任何出现该题的界面（错题页、收藏页、专项解析页、模考报告解析页、重练报告）
   读写的是同一条笔记。
2. **做笔记即收录**：写笔记的题自动进入本地题本（列表可搜索、可跳转编辑），并进入导出来源与重练池。
   收录的是**题面快照**（`store.snaps`），不是站点的错题关系——站点侧不会因为笔记多出任何一道错题或收藏。
3. 掌握状态、答错次数是题目属性，与来源无关：题本里的题在重练中答错，照常进本地错题统计、
   照常走「连对 2 次已掌握」。

## 后果

- 「错题本」从核心降级为来源之一（站点侧两档：错题本 / 收藏夹；本地两档：模考收录 / 题本，见 ADR 0005 决策 11）。
- 收录需要题目快照才能重练与完整导出；快照在**动笔那一刻**从当前页抓（专项解析页 / 错题页 / 收藏页），
  存量那批由取题那一路回填（重练取题与「与站点核对」共用），站点两个列表够不到的题按题目 ID 向解析接口要
  （ADR 0005 决策 33）。缺快照的题降级为「只有 240 字题干引文可看、可导出笔记」；
  有题面但缺解析正文的是**残缺快照**，另算一档（ADR 0005 决策 5）。
  本条原写「打开一次该题的解析页即自动补全」——那是一条没实现过的承诺，10-07 撤掉，
  落地方式见 ADR 0005 决策 8（改写后）、决策 33 与决策 34。
