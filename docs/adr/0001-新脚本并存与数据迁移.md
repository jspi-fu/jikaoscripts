# ADR 0001 — 8111 永久只发错题助手：验证通过才上架

- 状态：Amended（2026-10-03 机考助手已删除；本票原有的「两份并存」前提随之作废，仍生效的是发布口径）
- 日期：2026-09-26

## 背景

「错题助手」发布在脚本猫商店（script-show-page/8111），有真实用户装着它，浏览器里存着他们的笔记、
划线、答错次数和增量导出基线。商店的更新是推送式的——同一商店页发新版，用户没有「先不升」的选项。

## 决策

1. **8111 永久只发错题助手**，不用它承载未经真实页面验证的新形态能力。
2. **验证通过才上架**：没在真实页面跑过的版本一律不上。商店此刻停在哪个版本是时序状态，
   不写进本票（查法见决策 4）——本票只约束「什么样的版本才配上架」。
   仓库 `@version` 领先商店版本是常态，不是待修的偏差。
3. 错题助手**不冻结**，但只在「收录 / 导出 / 重练 / 笔记与筛选」这条线上演进。
   「任何题目都能记笔记」这类全站能力**当前不实现**——但它是 1.x 的候选方向（2026-10-04 用户定），
   届时以 ADR 0002 为设计基线，不再当作废案处理。**不得默认吸收**：真要开工得另立一票，
   至少定下作用域（哪些界面挂笔记入口）、存储形状（按 ADR 0004 的只增契约）与多标签合并语义。
4. 「验证通过」只认真实页面跑通过的能力线：模考收录已于 2026-10-02 端到端验证（场次 5158：
   收 49 题、48 道答错并入错题本、未做那道不计次）。此后任何未实测的改动都按「未验证」处理，
   具体到哪一份待测、卡在哪一环，不进仓库文档（查法见 `AGENTS.md`：读脚本头 `@version`、抓商店页、读 `localStorage`），不写进本票。

## 已作废（2026-10-03）

「新脚本独立文件 / 独立键 `gongan_exam_helper_<ctx>` / 独立商店页 / 首次运行整体复制旧键数据 /
设置面板保留『从旧版导入』/ 绝不回写旧键」——机考助手删除后这些都没有对象了。
它留下的 `gongan_exam_helper_<ctx>` 键如果还在浏览器里，是孤儿数据，删不删由用户定。
原「后果」里那条迁移隐患（先装新脚本、日后才用错题助手会被旧键覆盖）也一并消失。
