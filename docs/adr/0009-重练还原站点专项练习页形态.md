# ADR 0009 — 重练那一屏还原站点专项练习页的形态

- 状态：Accepted（2026-10-08 用户批准；**同日用户回看真页面后改判四处**——内容列要铺满、
  不限时也要能暂停、统计要一次给全、每题要带用时，见决策 4 / 12 / 13 / 14 就地修订）
- 日期：2026-10-08
- 相关：`docs/adr/0005`（笔记编辑区只有一份、题本对齐错题页）、`docs/adr/0007`（逐题用时）、
  `docs/adr/0008`（计时暂停的「可暂停」口径）

## 背景

重练原来是一层自造的界面：顶部一行灰底胶囊（第 N/M 题、已答、计时），中间一张 880px 带边框的卡片，
卡片下面一排 34px 圆角格子，再下面两颗「上一题 / 下一题」；交卷之后把整卷摊成一长页，
每题头上加一行我们自己造的标签（正确／错误／未作答 · 第 N 题 · 科目 · #题目ID · 答错次数）。

用户 2026-10-08 给了三张真页面截图（站点专项练习页的答题态与交卷态、错题页）并要求：
「重练应该尽量模仿…练习页…解析页，还原站点原生UI、功能设计，给用户贴近站点原本的体验」。

这件事的理由不是审美一致，而是**同一件事在两个地方学两套动作**：用户在站点专项页学会的
「左边答题卡跳题、右下角 F4/F5、头部交卷、勾只看错题」，进了我们的重练全部失效，
换成一套形状不同、词也不同（「第 N/M 题」vs「剩余时间」）的界面。重练是复盘的主入口，
这套分裂每天发生一次。

站点那一屏的形状是 curl 公开样式表实测出来的（`…/tiku/css/gongan.min.ebe4763b.css`，116559 字节），
不是照截图目测的：

- 蓝色头部 `.gongan2-header .content .nav`：底色 `#2178db`、高 60px、内容列 1000px 居中；
  `.remain-time` 宽 200px、里面 `<a>` 16px；`.jiaojuan a` = `height:30px;line-height:30px;
  padding:0 30px;border-radius:5px;background:#f97217`
- 左栏 `.question-container .sheet-box`：`float:left;width:230px;border-right:1px solid #e4e4e4;padding:10px`；
  板块名 `.operation-title` = `margin-top:20px;padding:8px;color:#0fa0ff;font-size:15px`，
  交卷后换 `.finished`（`color:#a0a0a0`）
- 答题卡格子 `ul.operation-btn li span`：`display:block;width:27px;height:27px;border:1px solid #2178db;
  background:#fff;color:#2178db;font-size:12px`；`.checked` 蓝底白字；`.checked.wrong` 与 `:hover` 是 `#f97217`；
  未答但错的 `.wrong` 是 `#d77e46`；`.stressed .stress` 是右上角一枚 `border-top:15px solid red` 的红三角
- 题号 `.sequence{width:40px}` + `.sequence-box{25px 见方;background:#b3c8e9}`
- 选项 `.choice .label .circle`：18px、`border-radius:80%`、`border:1px solid #b2b2b2`；
  `.right` = `5px solid #0c0`、`.wrong` = `5px solid red`、`.checked` = `5px solid #5188f5`；
  `.choice .content{padding-left:10px}`
- 题干 / 解析 / 材料同一档排版：`line-height:2;color:#222221;font-size:14px;word-break:break-all`
- 底部导航键面写着「上一题（F4）」「下一题（F5）」，另有「☆标记」与一颗齿轮

## 决策

1. **外壳照站点那一屏重排**：蓝色头部（左：重练 + 这份卷子的来源描述；右：时钟 + 交卷）→
   两栏身体（左 230px 答题卡栏、右内容列）→ 底部操作条。原来那行灰底胶囊与卡片下方的格子排全部撤掉。
   尺寸与色值一律抄上面那批实测值，**不自己定**；判据锁形状（`width:230px`、`27px`、`height:30px;
   line-height:30px;padding:0 30px;border-radius:5px`、`#b3c8e9`、`5px solid #0c0` / `red`），不锁语义色变量。
2. **交卷后一屏一题**（照站点解析页），不再把整卷摊成一长页。代价当场说清：
   丢掉「一页看完全卷」与那份逐题标签行（正确／错误 · 科目 · #题目ID · 答错次数）。
   得分与用时收进头部一行（`得分 1 / 3　已用 00:00`），对错与未做由**答题卡那一格的颜色**承担——
   站点就是这么表达的，我们原来那一行标签是把同一件事说第二遍。
   「题目ID」这种只有我们自己看得懂的一行删掉。
3. **「只看错题」是集合口径，不是遮罩**：勾上之后导航序列（`navIdxs()`）只含答错的题，
   答题卡格子、上一题、下一题、F4/F5 全部走这一份序列。
   原来那两颗「只看错题 / 全部」按钮是把别的卡片 `hidden = true`——F5 一按就跳回做对的题，
   那是假只看。**一道错题都没有时收回勾选并说一句**，否则界面停在第一题（做对的那道），
   看着像那颗复选框坏了。
   站点自己的「只看错题」把未做与答错并列展示（2026-10-08 curl 复算：
   `zhuanxiang/dati.template.html` 里那句 `view_only_wrong_subject && (item.result === 0 || item.result === 2)`，
   与 `CONTEXT.md`「未做」条一致），本脚本**不采纳**：未做不算答错这条口径在收录、分层、判分三处都成立，
   不该在复盘这一屏破例。
4. **限时是组卷面板的一个输入，留空 = 不限时**。「剩余时间」要有意义就得有个终点，
   而站点的参考时间挂在板块上（`label_info.total_seconds`），我们的题面快照里**没有这个字段**
   （`snapCopy` 只抄 10 个键），所以不能像站点那样自动摊出倒计时。
   设了限时才有到点自动交卷（照站点 `countdown<=0 → submitAction`）。
   ~~没设限时头部显示「已用时间」，**不摆暂停键**——沿用 `docs/adr/0008` 那条口径：
   没有会被倒计时触发的后果，就没有「暂停」这回事。~~
   **同日用户改判：暂停键无条件在。** 那条口径的适用对象是**站点那台考试时钟**——动它要往站点交一份
   少一截的用时，所以没有后果就不该给这个能力。重练的时钟是**我们自己的表**，暂停的意义是
   「离开一会儿不算进用时」，与会不会到点交卷无关。两条口径不冲突，冲突的是我把前一条搬错了地方。
   两条组卷路（「开始重练」与历史里「重练这套」）都要把限时传下去，漏一条就是其中一条永远不限时。
5. **暂停的实现是「不累加」，不是「装阀门」**：时钟只有一个 `runMs`，每秒 tick 只在未暂停时加上这一段。
   所以剩余时间与已用时间同时停得住。这与计时暂停那半的教训同源——
   给「已用」装阀门等于往交卷上报一份少一截的数，这里虽然不往站点报，
   但同一份数既显示又判分，冻一半就会自相矛盾。
6. **自动交卷不弹确认框**：只有手动交卷才问「还有 N 题未作答」。
   人不在座位上时弹框会把这一屏钉住，卷子永远停在未交卷状态。
7. **选一个选项不整屏重写**：`toggleAnswer` 只改这一题的圆圈 class 与答题卡那一格（`paintChoices` /
   `paintCells`），整屏 `renderQuiz` 留给切题、交卷、改「只看错题」这三件事。
   重写会把内容列的滚动位置与刚展开的解析一起收回。
8. **观察器在重练那一屏开着时整轮早退**：`refreshPageUI` 第一句 `if (!quizEl.hidden) return;`。
   那一屏是盖住全页的模态，底下的注入、页边轨道、划线重画谁也看不见。
   这条不是省 CPU：时钟每秒写一次头部，若头部写入走 `innerHTML`，就是每秒给 body 排一轮 childList 变更 →
   观察器白跑 → 白跑里再写界面。实测对照（夹具里那台 `GTH_CHURN`，2026-10-08 复算）：
   **有守卫**时答题态 3 秒 110 → 9 秒 110、交卷态 122 → 122、补充题本 380 → 380，**停住而时钟仍在走**；
   在临时副本上把那句早退删掉再量，同一页是 162 → 330（约每秒 28 个节点，不停）。
   配套的第二个守卫：时钟只改文本节点的 `nodeValue`（观察器只盯 `childList`，改字符不算变更）。
9. **底部那颗「标记」照站点做**：点一下在答题卡那一格画红角（`.gthq-cell.stressed:after`，
   照站点 `.stressed .stress` 那枚 `border-top:15px solid red`）。它是**内存态**，
   不进 `resume`、不进整库——站点那一屏的标记本来也只活到本次会话，
   而多一个持久字段就多一处「旧库里没有它」的降级说法。
10. **F4 / F5 真绑上并 `preventDefault`**：键面上写着这两个键，按了不动就是骗人；
    而 F5 不拦住默认行为会把整页刷掉。只在重练那一屏开着时拦。
11. **复盘那一屏仍走公共卡片渲染器**（`questionCardHtml`），所以决策 35 那份笔记编辑区、
    划线落点（`data-gth-qid` / `data-hls`）与右下角那条解析展开（`bindAnaToggle`，与题本同一份绑定）
    都不因为改版而断线。选项在复盘态是**纯文字**（照站点解析页那一屏），
    谁对谁错只在「正确答案：A　我的答案：B」那一行说。
12. **内容列跟着视口铺满，不照抄站点那条 1000px 居中列**（10-08 用户报「重练界面没有铺满全屏」）：
    第一版把 `.gthq-content` 限成 `max-width:770px` 并整体居中，理由是"站点就是 1000px 居中列"。
    但站点那一屏两侧还有它自己的导航与页边，**重练是盖住全页的模态**，照抄居中列只会留下两条大留白。
    现在只保留左 230px 答题卡栏，右列 `flex:1` 铺到底。
13. **交卷后头部一次给全五项统计**：得分 / 正确率 / 错题 / 未做 / 用时。
    一屏一题之后没有"整页扫一遍"这回事了，全卷的总览**只能靠这一行**——原来只写「得分 N/M　已用」，
    等于把决策 2 撤掉的整页一览又顺手带走了却没补上替代品。
14. **每题用时记在重练自己这一屏里**：`quiz.spent[id]`，每秒把这一段加在当前那一题头上，
    复盘时显示在那一题题号行的右端（不足一秒不显示，刚切进来就交卷的题该是空白）。
    这与 `docs/adr/0007` 那份逐题用时**是两套东西**：那份记在专项页、写自己的键 `gth_qtime_<ctx>`、
    要处理材料组与"认不出归属落 lost"；这一份只活在一次重练的内存里，不进整库也不进 `resume`——
    重练是一屏一题，归属没有歧义，也就没有那份复杂度存在的理由。
    **一处连带的旧落差要认**：从「最近组卷 → 重练这套」续刷时，恢复的是**题号与进度**，
    不是答案本身（`seedAnswered` 只带 `answeredIds`），所以续刷之前答过的那几题在交卷后算**未做**，
    五项统计里的得分 / 错题 / 未做与每题用时都只覆盖**这一段会话**。
    这不是这一轮引入的（旧版报告同样如此），但旧版只报「得分 N/M」，看不出来；
    现在头部明写「未做 N 道」，这一档就藏不住了。要修得先把答案一起存进 `resume`。

## 否决的选项

- **保留「一页摊开全卷」并再加一颗「一题一屏」开关**：两套复盘形态各自要一套导航与筛选，
  而用户要的是"贴近站点原本"，不是多一个选项。
- **照站点抄那颗齿轮（设置）与「连接正常」状态灯**：前者是站点考试参数（字号、快捷键方案），
  我们没有对应物；后者是站点考场网络探活，画出来就是一盏假灯。
- **把板块参考时间补进快照好自动算倒计时**：要给 `snapCopy` 加字段、要重抓一遍存量题，
  换来的只是省用户在限时框里打一个数字。
- **交卷后沿用站点「返回专项练习 / 查看解析」两颗键**：那是站点在**它自己的**做题页与解析页之间跳，
  我们这一屏没有"做题页"可回；上一题/下一题 + 退出才是这一屏需要的导航。

## 后果

- 重练与站点专项页之间的动作迁移成本降到零：答题卡跳题、F4/F5、头部交卷、只看错题，
  在两边是同一套手势。
- 丢掉的能力要认：一页看完全卷、按题翻标签行。全卷的总览收进头部那一行五项统计（决策 13），
  逐题的"哪题慢"由每题用时补（决策 14）——但**横向比较各题用时**（比如"哪题最慢"）没有了，
  要看得去笔记那一屏或导出。
- 「只看错题」从遮罩改成集合之后，`navIdxs()` 成为这一屏唯一的导航出处；
  以后要加「只看标记过的题」这类视图，是往这一份序列里再加一条筛选，而不是再写一套 `hidden`。
- 观察器早退这一条给后面所有"盖住全页的模态"立了个样子：**新加整屏浮层时要记得在 `refreshPageUI`
  里认它**，否则模态里任何一秒一次的写入都会白排一轮页面刷新。
- 首屏实测（2026-10-08，本机夹具 + 无头 Edge 截图）证到：答题态头部与两栏、格子按
  已答/当前上色、F4/F5 与答题卡跳题、限时 1 分钟按下暂停后时钟停在 00:54 三秒不动、
  恢复后从 00:54 继续走到 00:52、到点自动交卷并把头部换成「得分 0 / 3」、
  交卷后答题卡只剩错题那一格（`bad cur`）、复盘选项是纯文字带答案行。
  仍未证的仍然是 `@match` 与脚本猫自身的加载（那一条只能等用户真贴一次）。
