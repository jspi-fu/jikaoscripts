# ADR 0004 — 存储继续用 localStorage，不引入 GM_setValue

- 状态：Accepted
- 日期：2026-09-26

## 背景

机考系统各页面（index/analysis/mocks）同 origin，天然共享 localStorage；旧版全部数据就在 localStorage。GM_setValue 不受「清除站点数据」影响、容量更大，但需要数据迁移且脱离站点备份语义。

## 决策

继续用 localStorage（错题助手键 `gongan_tiku_helper_<ctx>`；机考助手那个键随脚本于 2026-10-03 一起删除），保留「备份全部数据 / 恢复 JSON」功能；不做 GM_setValue 迁移。

**数据形状是对外契约，不是内部细节**：任何改动形状的版本必须同时提供**可重复执行**的迁移函数，并且能吃下用户历史上导出过的备份 JSON——用户手里的旧备份和已装的错题助手数据一样是兼容面。改 `store` 结构时以这条为验收项。

契约冻结的是**顶层键与既有字段的语义**，不是字段清单。**允许**两类只增扩展：给已有记录追加可选字段、新增只增型的 id→值映射。判据是「旧数据缺这个字段时降级为何种行为」必须当场说得清，且不迁移、不回填也不出错（现例：`mockQs[].module` 缺失就落在「未分类」桶、`practiced` 缺失就视为「尚未重练」——两者都只让功能变保守，不会报错或丢数据）。只增型映射还要一并进 `mergeConcurrent` 的并集通路，否则多标签互写会被擦掉。并集比法各自定死：重练登记 `practiced` 按**次数取大**（不比时间戳，否则后写的小值会盖掉先写的大值），
模块映射 `qModule` **先到先得**（同一题的模块名不该有两个答案，后来的没有信息量）。
`store.resume` 是「按现算键查」的桶，不在并集通路里——它的老键另有处置，见下面那条。

**`lost` 标记的下游有四处**，误判一次就扩散到用户手里：删除线、「同色取消这条划线」被跳过、
页边批注栏的「N 条已失效」、以及一键整理写进笔记的「原文已变更」——最后一处会随导出的文件带走。
所以清洗只洗解析区（那里的失效多半是站点收起解析造成的），非解析区的 `lost` 是文本可见时连着两次判出来的
真信号，不动；恢复备份那一路要再洗一次，旧备份里那批多半同样是误判。

模考收录与练习题的合并只补两处：未作答的记录拿到作答、没有模块的记录拿到模块，**题面一律不动**；
答错计数的幂等靠 `store.mocks[场次].processed`，不靠题面比对。模考题 id 与练习题 id 是否同源**至今未证**——
真撞上键相同而内容不同，需要改成 `m + examId + '_' + qid` 那类合成 id 配内容指纹，现阶段只 `warn` 不自动改写，
因为自动改写等于替用户决定哪一份是真的。

顺序刷题的键 = `filterDesc + '|' + 顺序`，历史上有两代漂移，处置不同：来源标签由 `SRC_NAME.both`
（「错题+收藏」）改成逐项拼（「错题本＋收藏夹」）那一代**能归因**，读到就搬成新键并删老键（用户进度保住）；
硬约束是这两个名字再变，自愈就够不着老键。更早那一代**键里根本没记来源**（既不含「 · 」也不以「模考收录」开头），
搬到错题本 / 收藏夹 / 合并都是猜，而续刷先按题目 id 找、找不到才退回下标，搬错会真的跳题——所以那一代
只由界面上的「清理残留」删掉，不自动搬。判据守住这两条反例：可自愈那代不许被列进残留，在用库与别的 ctx
的在用库不许被列进存储键名单。

现状的版本化程度只有桶一级：`exported._v`（现例：`migrateExported` 把扁平的已导出 id 字典并进「错题本」桶，并补齐收藏夹 / 两者合并 / 模考三个桶），顶层 `hlLostMigrated`（现例：`migrateHlLost` 拿它把自己钉成只跑一次——解析收起期间划线曾被误判成 `lost`，每次加载都重洗会把后来在文本可见时真判出来的失效一起抹掉；缺这个键时的降级就是「再洗一次」，说得清且不出错），备份文件顶层另有 `_format` / `_version`。`store` 本身还没有顶层 `_v`——要把这条契约执行到底，得先补上它。

## 后果

- 用户「清除浏览器站点数据」会丢数据——靠备份功能与界面常驻提示兜底（沿用旧版策略）。
- 换零迁移成本、实现简洁；未来若确有容量/持久化痛点，再立新 ADR。
- 存量数据在浏览器里，形状不能随意改：改语义要多养一个迁移函数，只增字段要把「缺字段怎么降级」写进判据并让用例守住（现例：`tools/gth_logic_test.js` 的 T6 / T11）。
- 顶层 `_v` 缺失期间，靠「迁移函数必须可重复执行」这条兜底（现例：`migratedAt` 一类的幂等标记）。
