# ADR 0004 — 存储继续用 localStorage，不引入 GM_setValue

- 状态：Accepted
- 日期：2026-09-26

## 背景

机考系统各页面（index/analysis/mocks）同 origin，天然共享 localStorage；旧版全部数据就在 localStorage。GM_setValue 不受「清除站点数据」影响、容量更大，但需要数据迁移且脱离站点备份语义。

## 决策

继续用 localStorage（错题助手键 `gongan_tiku_helper_<ctx>`；机考助手那个键随脚本于 2026-10-03 一起删除），保留「备份全部数据 / 恢复 JSON」功能；不做 GM_setValue 迁移。

**数据形状是对外契约，不是内部细节**：任何改动形状的版本必须同时提供**可重复执行**的迁移函数，并且能吃下用户历史上导出过的备份 JSON——用户手里的旧备份和已装的错题助手数据一样是兼容面。改 `store` 结构时以这条为验收项。

契约冻结的是**顶层键与既有字段的语义**，不是字段清单。**允许**两类只增扩展：给已有记录追加可选字段、新增只增型的 id→值映射。判据是「旧数据缺这个字段时降级为何种行为」必须当场说得清，且不迁移、不回填也不出错（现例：`mockQs[].module` 缺失就落在「未分类」桶、`practiced` 缺失就视为「尚未重练」——两者都只让功能变保守，不会报错或丢数据）。只增型映射还要一并进 `mergeConcurrent` 的并集通路，否则多标签互写会被擦掉。**不允许**的是改顶层键、改既有字段含义、以及给带删除语义的数据（`notes` / `highlights`）做 naive 合并。

现状的版本化程度只有桶一级：`exported._v`（现例：`migrateExported` 把扁平的已导出 id 字典并进「错题本」桶，并补齐收藏夹 / 两者合并 / 模考三个桶），顶层 `hlLostMigrated`（现例：`migrateHlLost` 拿它把自己钉成只跑一次——解析收起期间划线曾被误判成 `lost`，每次加载都重洗会把后来在文本可见时真判出来的失效一起抹掉；缺这个键时的降级就是「再洗一次」，说得清且不出错），备份文件顶层另有 `_format` / `_version`。`store` 本身还没有顶层 `_v`——要把这条契约执行到底，得先补上它。

## 后果

- 用户「清除浏览器站点数据」会丢数据——靠备份功能与界面常驻提示兜底（沿用旧版策略）。
- 换零迁移成本、实现简洁；未来若确有容量/持久化痛点，再立新 ADR。
- 存量数据在浏览器里，形状不能随意改：改语义要多养一个迁移函数，只增字段要把「缺字段怎么降级」写进判据并让用例守住（现例：`tools/gth_logic_test.js` 的 T6 / T11）。
- 顶层 `_v` 缺失期间，靠「迁移函数必须可重复执行」这条兜底（现例：`migratedAt` 一类的幂等标记）。
