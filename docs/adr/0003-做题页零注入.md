# ADR 0003 — 做题页零注入；注入按「交卷状态」划界，不按文件名

- 状态：Amended（2026-10-06 就地修订：决策 1 与决策 2 的原前提被实测证伪，正文已改写；
  决策 3 仍生效；决策 4 描述的解析页内联挂载随「机考助手」于 2026-10-03 删除而失去实现对象，
  解析页的笔记入口现由 `docs/adr/0005` 接管，作用域只到专项解析页与模考报告页，`analysis.html` 不在内）
- 日期：2026-09-26

## 背景

接口探查确认：做题发生在独立的 `dati.html`（考试模式，数据接口无解析、无正确答案）与 `practice.html`
（练习模式）上，不在 `index.html` 内。用户确认三种模式（专项/全真/大赛）都是交卷后才有解析，
并选择做题时对已有笔记**无任何提示**（保持考试仿真）。

**2026-10-06 实测把「解析页是一种页面文件」这个前提推翻了**：curl 公开模板可复算——
`practice/dati.template.html` 71038 字节里 `analysis` 出现 **0 次**（练习模式确实没有解析），
但 `zhuanxiang/dati.template.html`（29156 字节）**同一份模板里既有答题态也有解析态**：
交卷按钮与倒计时挂 `ng-if="!isAlreadySubmit"`，解析块 `.analysis` 挂 `ng-if="isAlreadySubmit && isViewAnalysis"`，
答题卡是 `.sheet-box`（`position:fixed`，不是 `analysis.template.html` 里那个 `.right-sheet`），
题目按 `ng-repeat="subjectObj in localStorage.currentPartData.subjectList"` 配
`ng-if="localStorage.currentIndex == subjectObj.index"` **一屏只摊一道题**。
交卷态由 URL 查询驱动：站点 bundle 里 `status="finished"` → 取消计时 interval、置 `isAlreadySubmit`、调 `showAnalysis()`。
原票里「解析页一次只摊开一个试卷分区、右侧常驻 `.right-sheet` 答题卡」那两条约束**只对 `analysis.html` 成立**，
拿它当所有解析界面的通用形状，就得出了「不复用右侧轨道模型」这个当时看似必然的结论。

## 决策

1. **注入与否按「这场是否已交卷」判，不按文件名划界**。`practice.html` / `dati.html` / `guide.html`
   仍然零注入（它们没有解析可看）；`zhuanxiang.html` **不能**按文件名排除，因为它同时是答题页——
   它靠交卷状态闸门进来，闸门的具体信号与 fail-closed 姿态见 ADR 0005 决策 2。
2. 笔记入口存在于：错题页、收藏页、模考报告解析页（mocks SPA）、专项练习交卷后的解析界面，
   以及重练答题报告。`analysis.html`（全真 / 大赛交卷后的整分区逐题解析）**当前没有本脚本的任何入口**，
   是 ADR 0005 决策 1 明确留到下一步的那一页。
3. 「考试中翻自己的笔记」能力被明确放弃；如未来需要，只能作为显式开关加入，不默认提供。
4. 解析页若要挂笔记，**不复用**错题页/收藏页那套右侧轨道 + 批注气球的定位模型（那套几何围绕
   「题目区全部在界面上、跟着滚动走」设计，而解析界面要么一屏一题、要么右侧被答题卡占着）。
   本票当年选的内联挂载随机考助手作废；2026-10-06 的现行选择见 ADR 0005 决策 3——
   给笔记与划线/批注，不给页边批注轨道。

## 后果

- 脚本对考试仿真零干扰，且这份零干扰不是靠「不匹配那个文件」实现的，而是靠状态闸门——
  站点改掉驱动状态的参数名时，失效方向是「解析页没有笔记入口」，不是「笔记入口画在考试中间」。
- 练习模式即使站点侧将来改为即时出解析，本脚本也不会自动获得做题页笔记能力（需重新评估本票）。
- 解析页与错题页的笔记外观不一致是刻意的：换取切题、切分区后不丢，且不把批注挤到答题卡那一侧。
