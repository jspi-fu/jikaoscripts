# ADR 0003 — 做题页零注入，笔记只出现在交卷后的界面

- 状态：Partly Superseded（2026-10-03 机考助手删除；决策 1、3 对剩下的脚本仍是事实与约束，决策 2、4 描述的解析页内联笔记随该脚本作废）
- 日期：2026-09-26

## 背景

接口探查确认：做题发生在独立的 `dati.html`（考试模式，数据接口无解析、无正确答案）与 `practice.html`（练习模式）上，不在 `index.html` 内。用户确认三种模式（专项/全真/大赛）都是交卷后才有解析，并选择做题时对已有笔记**无任何提示**（保持考试仿真）。

解析页（`analysis.html`，已取到站点真实模板）另有两条约束：题目内容 `.question-box` 带 `ng-if="section.sectionId == currentSectionId"`，**一次只把当前试卷分区的题目渲染进界面**（其它分区的题目容器常驻但内部为空，切分区靠用户点左侧菜单或答题卡，不是滚动触发）；右侧另有一块常驻的答题卡 `.right-sheet` 占着页边距。

## 决策

1. `@match` **不包含** `dati.html` / `practice.html` / `guide.html`——做题页零注入，体验与无脚本完全一致。
2. 笔记入口只存在于：解析页（`analysis.html`）、错题页、收藏页、模考报告解析页（mocks SPA）。
3. 「考试中翻自己的笔记」能力被明确放弃；如未来需要，只能作为显式开关加入，不默认提供。
4. 解析页的笔记采用**内联挂载**：批注栏挂在题目节点内部，跟着分区切换一起被销毁和重建，靠题目 ID 重新取回内容。不复用错题页/收藏页那套右侧轨道 + 批注气球的定位模型——那套模型的几何是围绕「题目区一直全部在界面上、跟着滚动走」设计的，而解析页一次只摊开一个分区，右侧页边距又已经被答题卡占掉。

## 后果

- 脚本对考试仿真零干扰，不与「考试计时暂停」脚本在做题页重叠。
- 练习模式即使站点侧将来改为即时出解析，本脚本也不会自动获得做题页笔记能力（需重新评估本 ADR）。
- 解析页与错题页的笔记外观不一致（一个内联、一个浮动）是刻意的：换取切分区后不丢，且不把批注挤到答题卡那一侧。
