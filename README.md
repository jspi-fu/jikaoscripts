左侧菜单里有「机考助手」，点击打开助手面板：导出、组卷重练、笔记与本地数据都在这一页里。

## 题目右侧的批注栏

每道错题右侧的页边距里显示一条笔记栏。它位于题目文字右边的空白区域。空白不足 120 像素时不显示笔记栏，以免超出屏幕。笔记栏跟随题目区当前露出屏幕的部分：页面滚动，或题目区内部的滚动条滚动，笔记栏都跟着移动。

笔记栏默认只读。点击「＋ 添加笔记」，笔记栏变成编辑框，写入内容后保存。已经写过笔记的题目显示「编辑」按钮，可反复修改。

笔记栏显示这道题的全部划线。每条划线前面有一个圆点，黄色表示重点，红色表示易错。点击一条划线，编辑框打开，可修改该条划线的批注。

多条划线和各自的批注可以收集成一份笔记。点击「一键整理」，选择收集内容（仅划线 / 仅笔记 / 划线和笔记）与分组方式（按题目 / 按颜色）。还可以只收集解析区的划线；该项默认开启，取消勾选后，题干、选项和材料上的划线也进入笔记。整理结果显示预览，确认后复制或下载。

划线和批注按题目 ID 保存，不按页面位置保存。同一道题目在不同界面里显示的内容相同。

## 划线与批注

在题干、选项或解析里选中一段文字，工具条立刻出现。工具条上有三个动作：重点（黄色）、易错（红色）、批注。

键盘可以代替鼠标：`Alt+1` 标为重点，`Alt+2` 标为易错，`Alt+3` 打开批注输入框。`Esc` 关闭工具条和弹层。

对已经划过的一段文字重新选择一次：点击相同的颜色取消这条划线；点击另一种颜色改变这条划线的颜色。

每条划线保存自己的批注。同一道题目可以有多条划线，各自的批注互不影响。

脚本按「原文 + 前面的文字 + 第几次出现」定位一条划线，不保存页面节点。站点改写题目文字后，脚本可能找不到原来的位置。这时该条划线标记为失效，批注仍然保留。

## 复制题目

每道题目前面的操作条上有「复制题目」按钮。同一条上还有答错次数、掌握状态和笔记入口。

点击一次，题干、材料、选项和解析一起进入剪贴板，可粘贴到搜题工具、AI 对话或笔记软件里。

四颗复制键（题目操作条、解析页那一排、划线工具条、整理本题那一屏）反馈统一：成功了在页面底部弹一句「复制成功」，没成功就说没成功，不再各写各的。

部分题目在文字中间插入图片，例如「如下图所示」。这类图片保存成 Markdown 图片语法，位置保持在文字之间。相对地址自动补全成完整地址，粘贴到其他位置后仍可打开。

## 导出

支持三种格式：Markdown（.md）、Excel（.xlsx）、CSV（.csv）。

「导出新增」只导出以前没有导出过的题目。脚本在本地保存一份已导出题目清单。第一次导出时，当前筛选下的全部题目都算新增；之后每次只导出新增加的题目。

「导出全部题目」重新导出一份全量文件。「重置增量基线」清空已导出清单。

已导出清单按来源分别保存：错题本、收藏夹、两者合并、模考收录各一份。同一道题目同时在错题本和收藏夹里时，一边导出过不会影响另一边。

导出的表格有 14 列：序号、科目、来源、材料、题干、选项、「你的答案」、正确答案、答错次数、解析、笔记、划线摘录、掌握状态、题目 ID。「来源」列写错题本 / 收藏夹 / 错题本＋收藏夹 / 模考#场次；来源与科目要等「与站点核对」跑过一次才填得满，没填上时写「练习」。这一趟核对现在摊开错题页或收藏页就会自动跑一次，也可以点「升级后点我」手动跑。

文件名形如 `上岸村错题_新增_20260917_2130.md`。

## 组卷重练

先选择来源。来源是一个勾选式下拉，错题本、收藏夹和模考收录可任意组合。一道题目在多个来源里出现时只出现一次。

再选择范围。范围有两种：按日期（当天 / 本周 / 本月 / 近三月 / 全部）和按科目（公安专业知识 / 行政职业能力测试）。

选择行政职业能力测试时可按模块勾选题型。模块名称取自站点的行测考点表。可多选，也可全不选；全不选表示全部模块。

勾选模考收录时多出一排模考模块。这一排的选项只来自已经收录的题目，没有模块名的题目落在「未分类」。

题量默认 20，最大 500。顺序有三种：随机、原序、倒序。

随机组卷按四个层次选题，顺序是：顽固错题 → 尚未重练 → 练过但未掌握 → 已掌握。同一层内按答错次数加权。题量设置得小，抽到的即是最需要重看的题目。手动标记为已掌握的题目排在最后一层，仍可能被抽到。

原序和倒序会记录进度。下次点击「开始重练」，脚本从上次那道题继续；中途退出，下次跳到第一道没有作答的题目。需要从头开始，点击「从头开始」。

最近三次组卷保留在「最近组卷」里。点击「重练这套」，脚本按当时的条件重新取题，并与当时的题目清单取交集。错题本里已经删除的题目自动跳过，脚本显示找回了多少道题。

![组卷面板](https://imglink.cc/cdn/OeJAWHoM0I.png)

## 重练界面与报告

重练那一屏照站点专项练习页的样子做：顶部一条蓝色头部（左边写这份卷子从哪来，右边是时钟与「交卷」），
左边一栏答题卡，右边是题目，底下一排「标记 / 上一题（F4）/ 下一题（F5）/ 退出」。
`F4` / `F5` 与 `←` / `→` 都能翻题，`Esc` 退出，点答题卡上的数字直接跳到那一题。

组卷时可以填「限时（分钟）」：填了就显示剩余时间，到点自动交卷；不填就显示已用时间。
两种情况下都可以按头部那颗暂停键——离开一会儿不算进用时。

交卷之后**一屏一题**（和站点看完一卷之后的样子一样）：题干下面是选项、解析，
以及「正确答案 / 我的答案」那一行；这一题花了多少时间写在题号那一行的右端。
头部一次给出五项：得分、正确率、错题数、未做数、总用时。
答题卡那一格的颜色就是说清这道题结果的地方：蓝底是做过的，橙棕底是答错的，灰底是没做的。
勾上「只看错题」之后，答题卡与翻页都只在答错的那几题里走（没做的题不算答错）。

## 冻结站点倒计时

专项练习页，以及练习页的考试模式（地址里带 `page_type=random`），在头部那行时间旁边多出一颗键。
没暂停时它是白底蓝色的暂停图标，悬浮写「点这里冻结计时」；点一下冻结，键变成琥珀色、图标换成播放，
悬浮写「已冻结，可以放心离开」。再点一下解冻。

冻结期间站点那一列每秒一次的自减停在原地：到点自动交卷、以及考试模式里「某块时间用完就随机跳到别的板块」
都不会被触发。已用时间照站点自己的时钟继续走——交卷上报的就是它，脚本不替你少报一分钟。

练习页的练习模式上脚本一个节点都不建，页面保持原样。站点自己那行「离线时间」是另一台表，冻结不管它。

悬浮说明里带着诊断：取页面走的是哪条路、扫到几台计时器、装上几个阀门、已用多久。
按下时一台计时器都没扫到，只是站点还没跑起来，那颗键留在原地等；扫到了却装不上才算停不住——
这时摘掉键，在站点那行时间上留一道虚线下划，原因写进悬浮说明。

## 逐题做题用时

专项练习页每秒把 1 秒记在当前那道题头上。资料分析那一类整段材料摊在一屏，记账单位就是**整段材料**
（不拆分、不均摊），展示时写成区间「第 11–15 题」。这份账只存在本机，按场次分开，换一场是另一份。

交卷之后在专项解析页：

- 每题右上角那一排显示这一题（或这一段材料）的用时；
- 内容区右上角那颗「本场做题用时」点开是逐题清单，一行一题；
- 合计 = 各题之和 + 未归属，这三个数在悬浮说明里对得上。

暂停期间的那一秒照样记在当前那道题头上（要的是真实用时，离开两分钟就是两分钟），
清单里另写一句「其中暂停多久」。认不出当前题的那一秒落进「未归属」，不猜给上一题。

## 专项解析页上的那一排

专项练习交卷之后（地址里带 `status=finished`），每题右上角多出一排：「笔记」点开是这一题的笔记浮窗
（预览态给「编辑」，编辑态给「保存 / 取消」，点空白或收起浮窗都等于取消，草稿不写进库）、
「复制题目」、「整理本题」，右边跟着三枚状态：这道题的题面在不在本机补充题本里（已收录 / 未收录）、
有几条划线、这一题花了多久。站点自己的「收藏本题」与「纠错」仍在那一行上，脚本不动它们。

## 题目里的图片自动缩到文字大小

题面里常有公式、分式、竖式，站点把它们切成一张张图片塞在文字中间——一张 1221×251 的式子能把整页撑开。
脚本分两步处理每张图片：先问它在句子里扮演什么角色，「如下图所示」领起的那张是图形，保持原样；
等号后面、单位前面那种是式子，要缩。再问它该占几行，按图片自身的宽高折算，落成一行的行高或两行的行高。

被缩小的图鼠标上去是放大镜，点开放大看原图，点空白或 `Esc` 收回——认错了也不把人堵死。
材料（资料分析那一大段）里的图片一个像素都不动。

## 补充题本

左菜单里「补充题本」那一颗，收的是**站点没收进来的题**：本机记过的题都算——写过笔记、划过线、从模考里收录进来，
或者站点曾经收过、后来从错题本与收藏夹里清掉了（2026-10-14 站点清空过一次错题本，那批只剩本机这一份账）。
判据是「站点此刻没有它」：站点收了的你不用管，站点没收的这里才收。

摊开的样子与站点错题页一致：每题头上是答错次数、掌握状态、「笔记」与「复制题目」，
题号在左侧那个淡蓝方块里，解析默认收起、点右下角那条「展开 查看解析」摊开，
笔记写在题目右边那一栏里。一页 20 题，底下翻页。

顶部三样筛选：科目、模块、关键词（搜题干、解析或你写的笔记）。「清空筛选」在你真筛过之后才出现。

缺题面或缺解析的题，摊开这一屏就会自己去向站点要，当前这一页先补，不用你点任何按钮。
一道题只要站点后来把它收了，下一次核对时就自动离开这里。

## 掌握状态与顽固错题

每道题目记录答错次数。答错一次进入错题本时计 1 次。站点接口不提供这个数值，由脚本在本地累计。

答对一次后，题目状态变为「待巩固 1/2」。连续答对两次后，状态变为「已掌握」，题目上出现绿色标记。中间答错一次，计数清零，状态回到未掌握。

题目前的操作条上可手动标记已掌握，也可取消。

答错满 3 次的题目标记为「顽固错题」，显示为红色。随机组卷把它们排在第一层。

## 全真模考收录

站点的全真模考成绩不进入错题本。脚本在模考页面右下角显示「模考收录」浮标。

进入某一场考试的解析页面后，脚本自动收录题目：题干、材料、选项、「你的答案」、正确答案、解析。浏览到哪一道题，就收录哪一道题。

点击「收齐全场答错题」，脚本逐题补齐本场全部答错题目所需的题面。面板按题显示进度，例如「正在补题面 12 / 49（失败 0）…」。重复扫描不会重复计数。

判分规则与站点解析页一致：答错的题目进入错题本；没有作答的题目不进入错题本，也不计入答错次数，只保留在收录结果里。

收录后回到错题页，这些题目可以和练习错题一起导出、组卷、记笔记和统计掌握状态。

全部收录的题目（包括答对的题目）在导出面板选择「模考收录」时单独导出，表格的「来源」列标明模考场次。

## 搜索与筛选笔记

笔记面板可按笔记内容或题干搜索。

笔记面板有五个筛选维度：科目、模块、来源（练习题 / 错题本 / 收藏夹 / 两处都有 / 模考收录）、掌握状态、内容（只有笔记 / 只有划线 / 两者都有）。「练习题」包含后三种出处。来源细分要等「与站点核对」跑过一次才填得上；没填上的题按「练习题」算，仍能按练习题筛。

模块取自每道题目自带的考点编号，脚本在载入题目时把它换算成所属模块名称。

筛选后点击「导出笔记(MD)」或「一键整理」，只有列表里可见的题目进入结果。

## 本地数据

全部数据保存在本机当前浏览器里（localStorage），不上传到站点。

「备份全部数据」导出一份 JSON 文件，包含题目、笔记、划线、掌握记录、答错次数、已导出清单、组卷历史、重练进度和模考收录（含模考场次登记）。

「恢复备份」从一份 JSON 文件把数据读回来。

「清空本地数据」删除本脚本保存的全部数据，该操作不能撤销。

「升级后点我」是一颗绿色的键，换了新版脚本之后点它一下就行。它按顺序做三件事：先清掉本机已经用不上的旧记录（已停用脚本留下的整库、排查时产生的历史快照、命名规则变更前留下的旧刷题进度，以及题号底册里找不到的题面快照（本机再也没记过的那批）），**删之前会列出一张清单问你一次**；接着连一次站点，把笔记与划线对应的题补上模块、科目和来源，并认出哪些题站点自己已经收了——补充题本靠这一条决定谁该留下。需要联网，几秒钟。你的笔记、划线、掌握状态和已收录的题都不受影响。

补模块要跑两趟取题：先按日期把错题本与收藏夹里的题目全部过一遍，再按科目把公专的题目过一遍。行测的科目按题目自带的考点落在行测考点树里判定；两边都判不出的留空。跑完报数：过了几题、新登记几条模块、几条科目、几条来源，以及笔记与划线里还缺几题。模考收录的题目自带模块与科目。已经不在错题本与收藏夹里的题目取不到考点，只能等那道题再出现一次。已有值一律不覆盖，只补空着的地方。

清理浏览器数据、更换设备或重装系统之前，需要先备份。
